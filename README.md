One original line of fortune-cookie wisdom, written for the developers who
keep the world's legacy code alive.

Bounty: https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44

## The fortune

> The code you refuse to delete will outlive the code you brag about; tend both like the legacy they already are.

## How to run

```sh
python3 main.py
```

This writes the fortune line to `/output/entry.txt` (UTF-8, 111 characters).
